
### What follow up actions are allowed?

	|--------|-----------------------------------------------------------------------------------------|
	|        |                              2nd action (follow up)                                     |
	|--------|-----------------------------------------------------------------------------------------|
	|        |        | Lock   | Unlock | Place  | Free   | Win    | Loss   | Tie    | Return | Cancel |
	|        |--------|--------|--------|--------|--------|--------|--------|--------|--------|--------|
	|        | Lock   |  YES   |  YES   |  YES   |   NO   |   NO   |   NO   |   NO   |   NO   |  YES***|
	|        |--------|--------|--------|--------|--------|--------|--------|--------|--------|--------|
	|        | Unlock |   NO   |   NO   |  YES   |  YES   |  YES   |  YES   |  YES   |  YES   |  YES * |
	|        |--------|--------|--------|--------|--------|--------|--------|--------|--------|--------|
	|        | Place  |  YES   |  YES   |  YES   |  YES   |  YES   |  YES   |  YES   |  YES   |  YES***|
	| 1st    |--------|--------|--------|--------|--------|--------|--------|--------|--------|--------|
	| action | Free   |   No   |   NO   |   NO   |  YES   |   NO   |   NO   |   NO   |   NO   |  YES * |
	|        |--------|--------|--------|--------|--------|--------|--------|--------|--------|--------|
	|        | Win    |   NO   |   NO   |   NO   |  YES   |   NO   |   NO   |   NO   |   NO   |  YES * |
	|        |--------|--------|--------|--------|--------|--------|--------|--------|--------|--------|
	|        | Loss   |   NO   |   NO   |   NO   |  YES   |   NO   |   NO   |   NO   |   NO   |  YES * |
	|        |--------|--------|--------|--------|--------|--------|--------|--------|--------|--------|
	|        | Tie    |   NO   |   NO   |   NO   |  YES   |   NO   |   NO   |   NO   |   NO   |  YES * |
	|        |--------|--------|--------|--------|--------|--------|--------|--------|--------|--------|
	|        | Cancel |   NO   |   NO   |   NO   |   NO   |   NO   |   NO   |   NO   |   NO   |  YES * |
	|--------|--------|--------|--------|--------|--------|--------|--------|--------|--------|--------|
	
 * Cancel action can only be applied once

 ** you can **Cancel** action of type **Lock** and **Place** only if it has no other un-cancelled actions referencing it
